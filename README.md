Sambal Rush — run a warung kitchen: orders land on the board, you grab ingredients (1–8), chop veg and chili, cook in two pots, and serve before the timer runs out. Four original dishes (Nasi Goreng, Mie Goreng, Sate Ayam, Es Teh), a 150-second shift, combo tips, and a service rush that gets faster as the clock runs down. Plain static files, no network, deterministic per seed. Play it with keyboard and mouse in desktop Chrome.

## Run it

```sh
node main.ts
```
